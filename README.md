# 🐾 Mi Mascota

> **⚠️ PROYECTO LEGACY**  
> Este proyecto se encuentra en estado finalizado y descontinuado.

## 📋 Descripción

Red social diseñada para dueños de mascotas que permite gestionar la información de sus compañeros peludos y conectar con otros propietarios de mascotas. La plataforma ofrece herramientas para el seguimiento del cuidado de mascotas y facilita la comunicación entre la comunidad de amantes de los animales.

## ✨ Funcionalidades Principales

### 👤 Gestión de Usuario
- Registro y autenticación de usuarios
- Perfil personalizable

### 🐕 Gestión de Mascotas
- Registro de mascotas con información detallada
- Seguimiento de eventos importantes:
  - 🛁 **Baños**: Control de higiene
  - 💉 **Vacunas**: Historial de vacunación
  - 🏥 **Visitas veterinarias**: Registro médico
  - ➕ **Eventos personalizados**: Otros cuidados específicos

### 🗣️ Sistema de Foros
La plataforma incluye tres categorías principales de foros:

#### 🔍 "Me Perdí"
- Publicaciones para mascotas extraviadas
- Ayuda comunitaria para localizar mascotas perdidas
- Sistema de alertas geográficas

#### 💕 "Busco Pareja"
- Conexión entre propietarios para reproducción responsable
- Perfiles de mascotas disponibles para apareamiento
- Información genética y de salud

#### 🏠 "En Adopción"
- Mascotas en busca de nuevo hogar
- Proceso de adopción responsable
- Verificación de adoptantes potenciales

## 🛠️ Tecnologías
- **Backend**: PHP 7
- **Base de datos**: MySQL
- **Frontend**: HTML5 y CSS3
